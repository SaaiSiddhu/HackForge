## 5. Concise Submission Description (Copy-Paste Ready)

Use the following concise summary for the hackathon submission form (strictly reflects implemented `T1` and `T2` functionality):

> **HackForge (Claimed & Verified Tiers: T1, T2)**
>
> HackForge is a self-hosted, offline-capable hackathon submission, judging, and statistical score calibration platform built with FastAPI, SQLAlchemy 2.0, Alembic, and PostgreSQL 17. A single `docker compose up` runs migrations `0001–0005` and idempotently seeds the official 41-project, 30-judge, 126-review `Sample Hack 2026` (`evt_01`) fixture alongside an open demonstration event (`evt_open_demo`) under a PostgreSQL advisory lock, operating 100% offline with zero external runtime dependencies.
>
> **Tier 1 (Core Portal)**: Supports organizer event/track/prize/question setup, Argon2id authentication with SHA-256 database sessions and CSRF protection, single-team-per-event enforcement with `SELECT ... FOR UPDATE` capacity locking on team invitations, optimistic concurrency-controlled (`expected_version`) draft and final project submissions, Pillow-validated image uploads (`PNG`/`JPEG`/`GIF`/`WebP`) served via access-controlled media routes, server-side deadline enforcement, and a searchable, track-filterable public project gallery.
>
> **Tier 2 (Judging, Normalization, Snapshots & Exports)**: Provides versioned weighted rubrics, one-time cryptographic judge invitations, conflict-aware batch judge assignment, isolated judge queues with draft/finalized scoring, and dual-role access restrictions. The statistical engine (`zscore_v1`) calibrates judge scores within comparable `(track, rubric)` cohorts using population Z-scores, automatically excludes small-sample ($N_j < 3$, e.g., `jdg_01`) and zero-variance ($\sigma_j \le 10^{-6}$, e.g., constant-score judge `jdg_07`) judges from normalization while preserving their raw scores, detects disconnected evaluation networks via BFS (withholding unqualified global normalized ranks across disconnected components), freezes reproducible results in `REPEATABLE READ` canonical v2 manifest snapshots with staleness detection, and exports 6 RFC 4180 CSV reports. Verified by 100 automated Pytest tests and unmodified `python3 run.py .dogfood.toml` (`claimed T1 T2, verified T1 T2`).
